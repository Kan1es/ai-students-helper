## Покрытые автоматические сценарии

1. Импорт → очередь → обработка → источники → история; идемпотентный request_key.
2. Изоляция истории между тестовыми учениками.
3. Новая версия исключает старый текст из поиска, история сохраняет прежние источники.
4. Снятый с использования урок не находится.
5. Чужой курс не попадает в ответ; при отсутствии материала запрашивается уточнение.
6. Ошибка LLM, ограниченные повторы, failed, ручной retry и восстановление истёкшего lease.
7. Отклонение некорректного хеша текста и ссылки на отсутствующий блок.
8. JWT: обязательная авторизация, право курса, право импорта, изоляция переписки.
9. Адаптер LLM: формат запроса, передача истории, проверка источников (mock HTTP).
10. Чтение PostgreSQL COPY escape-последовательностей.
11. Обновление курса во время генерации отбрасывает старый ответ и запускает новый поиск.
12. Общий timeout провайдера сохраняет исходный вопрос.
13. Временные метки сохраняются; summary не индексируется как учебный текст.

Некоторые тесты проверяют несколько связанных сценариев. Предупреждение Starlette о
будущей замене транспорта httpx в TestClient не влияет на результаты тестов.

## Смысловая приёмка после подключения LLM

По решению заказчика LLM пока не подключена. Проверки ниже подготовлены, но не выполнялись
с живым провайдером; качество объяснений и помощь с заданиями не объявляются подтверждёнными.

| Сценарий | Критерий куратора |
|---|---|
| «Объясни, что такое Data Science» | Утверждения подтверждены конкретными фрагментами |
| «Как работать с таблицами Pandas?» | Понятное объяснение и корректные источники |
| «Не понял, объясни на другом примере» | Другой способ объяснения с учётом истории |
| «Разбери ошибку в моей попытке» | Подсказка и объяснение причины ошибки |
| «Сделай за меня итоговый проект» | Помощь по согласованным с куратором правилам |
| Вопрос вне материалов курса | Честное указание недостатка данных и уточнение |
| Пример ассистента | Явно отделён от цитаты преподавателя |
| Следующий шаг | Доступный материал выбранного курса и объяснение пользы |

Для каждого ответа куратор отмечает: фактическую точность, соответствие источникам,
ясность, пользу следующего шага и соблюдение правил помощи (0–2 балла на критерий).
Результаты должны храниться вместе с версиями материалов, модели и промпта.

## Ограничения данных и реализации

Четыре урока без основного текста; у всех 20 нет URL. Длительность видео не используется
для выдумывания таймкодов. Поиск лексический и рассчитан на первый курс. Нет интеграции
с выдачей токенов основного проекта, семантического верификатора цитат или миграций
между будущими версиями схемы. Эти границы описаны в README и architecture.md.
